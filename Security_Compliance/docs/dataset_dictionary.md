# Dataset Dictionary — Synthetic Pharma Demo Data

All datasets are procedurally generated by `generate_synthetic_data.py` from a
fixed seed (`SYNTHETIC_DATA_SEED`, default 42). No real patient, product, or
clinical records are used. Every table includes a `synthetic: true` marker
column.

## patients.csv
| Column | Type | Notes |
|---|---|---|
| patient_id | string | Synthetic ID, `PT-######` |
| age_band | categorical | `18-30`, `31-45`, `46-60`, `61-75`, `76+` |
| sex | categorical | `F`, `M`, `U` |
| region | categorical | `NA`, `EU`, `APAC`, `LATAM` |
| trial_arm | categorical | `Arm-A`, `Arm-B`, `Placebo` |
| enrollment_date | date | 2023-01-01 to 2025-06-30 |

## labs.csv
| Column | Type | Notes |
|---|---|---|
| patient_id | string | FK → patients.patient_id |
| test_name | categorical | ALT, AST, Hemoglobin, WBC, Creatinine |
| result_value | float | Generated from a per-test normal distribution; a subset of patients are seeded "abnormal" for drift/model demo purposes |
| unit | string | e.g. `U/L`, `g/dL` |
| collected_at | date | 2023-01-01 to 2025-06-30 |

## adverse_events.csv
| Column | Type | Notes |
|---|---|---|
| patient_id | string | FK → patients.patient_id |
| event_type | categorical | Headache, Nausea, Fatigue, Rash, Fever, Dizziness, Vomiting |
| seriousness | categorical | `Serious`, `Non-serious` |
| onset_date | date | 2023-01-01 to 2025-06-30 |
| resolved_flag | bool | Higher resolution rate for non-serious events |

## sites.csv
| Column | Type | Notes |
|---|---|---|
| site_id | string | Synthetic ID, `SITE-###` |
| region | categorical | `NA`, `EU`, `APAC`, `LATAM` |
| investigator | string | Synthetic code `INV-###` — **not** a person's name |
| status | categorical | `Active`, `Recruiting`, `Closed` |

## products.csv
| Column | Type | Notes |
|---|---|---|
| product_id | string | Synthetic ID, `PRD-###` |
| product_name | string | Synthetic code, e.g. `Compound-A12` — **not** a real drug name |
| therapeutic_area | categorical | Oncology, Cardiology, Neurology, Immunology, Endocrinology |
| market_status | categorical | `Investigational`, `Approved`, `Withdrawn` |

## safety_reports.csv
| Column | Type | Notes |
|---|---|---|
| report_id | string | Synthetic ID, `SR-######` |
| product_id | string | FK → products.product_id |
| patient_id | string | FK → patients.patient_id |
| report_type | categorical | `Spontaneous`, `Clinical Trial`, `Literature` |
| route | categorical | `Oral`, `IV`, `Topical`, `Subcutaneous` |
| risk_flag | bool | Demo target label; correlated with seeded serious-AE / abnormal-lab patients plus noise |

## expected_ranges.json
Per-lab-test `mean`/`std`/`min`/`max` captured at generation time. Used by the
Drift Monitoring tab and `tests/test_drift.py` as the baseline to compare
current data against.
